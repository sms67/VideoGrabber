# ویدیوگرابر (VideoGrabber)

برنامه ویندوزی ساده و قدرتمند برای **دانلود ویدیو از هر سایتی** — یوتیوب، اینستاگرام، تیک‌تاک، توییتر/X، فیس‌بوک، Reddit، Twitch، آپارات و هزاران سایت دیگر.
موتور دانلود این برنامه **yt-dlp** است؛ یعنی هر سایتی که yt-dlp پشتیبانی می‌کند، این برنامه هم پشتیبانی می‌کند.

> زبان برنامه دوزبانه است (فارسی/انگلیسی) — از نوار بالای پنجره با دکمه «English / فارسی» عوضش کن.
> روی هر سیستم دیگری که پایتون دارد (ویندوز/لینوکس/مک) هم اجرا می‌شود.

---

## امکانات

- **تحلیل لینک و انتخاب کیفیت:** بعد از چسباندن لینک، برنامه کیفیت‌های موجود (تا 4K) را با حجم تقریبی نشان می‌دهد و انتخاب می‌کنی — یا فقط صدا (MP3) می‌گیری.
- **پلی‌لیست کامل:** لینک پلی‌لیست یوتیوب را بده؛ لیست ویدیوها با تیک باز می‌شود، هر کدام را خواستی انتخاب و برای همه یک کیفیت تعیین کن.
- **صف دانلود چندگانه:** چند دانلود هم‌زمان (قابل تنظیم از ۱ تا ۵) با نوار پیشرفت، سرعت، حجم و زمان باقی‌مانده برای هر ردیف.
- **لغو / تلاش دوباره / پاک‌سازی صف.**
- **کوکی مرورگر:** ویدیوهای محدودیت سنی (یوتیوب) یا خصوصی را می‌تواند با کوکی کروم/فایرفاکس/ادج شما دانلود کند.
- **دوزبانه + راست‌چین کامل برای فارسی.**

## شروع سریع (ساده‌ترین راه)

پیش‌نیاز: [پایتون](https://www.python.org/downloads/) (نسخه 3.9 به بالا). موقع نصب حتماً تیک **Add python.exe to PATH** را بزن.

1. **`install.bat`** را دابل‌کلیک کن (فقط بار اول — پکیج‌ها را خودکار نصب می‌کند).
2. **`get-ffmpeg.bat`** را دابل‌کلیک کن (برای بهترین کیفیت و MP3 لازم است؛ یک‌بار).
3. **`run.bat`** را دابل‌کلیک کن. تمام!

استفاده: لینک را بچسبان → **تحلیل لینک** → کیفیت را انتخاب کن → **افزودن به صف**. همین.

## ساخت نسخه EXE (بدون نیاز به پایتون)

اگر می‌خواهی یک فایل `VideoGrabber.exe` مستقل داشته باشی:

1. **`build.bat`** را دابل‌کلیک کن (اینترنت می‌خواهد و چند دقیقه طول می‌کشد).
2. خروجی اینجاست: **`dist\VideoGrabber.exe`**
3. برای پشتیبانی MP3 و بهترین کیفیت، `ffmpeg.exe` را کنار EXE بگذار:
   - یک‌بار `get-ffmpeg.bat` را اجرا کن (در همان پوشه ffmpeg.exe می‌سازد) و دوباره `build.bat` بزن — خودش کپیش می‌کند.

حجم EXE حدود ۱۰۰ مگابایت است (به‌خاطر yt-dlp و Qt) — طبیعی است.

> آپدیت موتور دانلود در حالت سورسی: **`update.bat`** را بزن.
> در حالت EXE: دوباره `build.bat` اجرا کن.

## تنظیمات

از تب **تنظیمات**:

| گزینه | توضیح |
|---|---|
| پوشه دانلود | پیش‌فرض: `Downloads\VideoGrabber` |
| دانلود هم‌زمان | ۱ تا ۵ |
| کوکی مرورگر | برای ویدیوی محدودیت سنی/خصوصی — اول در کروم/فایرفاکس لاگین کن، بعد همین‌جا مرورگر را انتخاب کن |
| کیفیت پیش‌فرض پلی‌لیست | برای ویدیوهای پلی‌لیست (تک‌ویدیو همیشه می‌پرسد) |
| زبان | فارسی / English |

تنظیمات در `%APPDATA%\VideoGrabber\settings.json` ذخیره می‌شود.

## سوالات متداول

**۱) فلان سایت دیگر دانلود نمی‌کند / خطای 403 یا «unable to download» می‌دهد.**
سایت‌ها مرتب تغییر می‌کنند؛ اول **`update.bat`** را اجرا کن (به‌روزرسانی yt-dlp معمولاً حلش می‌کند). اگر نشد، چند ساعت صبر کن تا yt-dlp آپدیت جدید بدهد.

**۲) ویدیوی یوتیوب «Sign in to confirm your age» می‌دهد.**
در تب تنظیمات، کوکی مرورگر را روی همان مرورگری که به یوتیوب لاگینی بگذار.

**۳) MP3 یا کیفیت بالا خطای ffmpeg می‌دهد.**
`get-ffmpeg.bat` را اجرا کن. (بدون ffmpeg، دانلود کیفیت‌های پایین همچنان کار می‌کند.)

**۴) فایل دانلودشده کجاست؟**
پوشه پیش‌فرض `Downloads\VideoGrabber` — یا دکمه «بازکردن پوشه دانلود» داخل برنامه.

**۵) دانلود کند است؟**
در yt-dlp سرعت معمولاً به سایت مقصد بستگی دارد؛ تعداد دانلود هم‌زمان را کم کن تا به هر دانلود پهنای بیشتری برسد.

## ساختار پروژه

```
VideoGrabber/
├── main.py            ← نقطه شروع برنامه
├── app/
│   ├── main_window.py ← پنجره اصلی، جدول صف، تنظیمات
│   ├── dialogs.py     ← دیالوگ کیفیت و پلی‌لیست

├── requirements.txt
├── run.bat            ← اجرای برنامه
├── install.bat        ← نصب خودکار پیش‌نیازها
├── build.bat          ← ساخت EXE مستقل
├── get-ffmpeg.bat     ← دانلود خودکار ffmpeg
└── update.bat         ← به‌روزرسانی yt-dlp
```

### English (short)

VideoGrabber is a bilingual (Persian/English) Windows GUI downloader built on **PyQt6 + yt-dlp**.
Quick start: install Python → double-click `install.bat` → `get-ffmpeg.bat` (once) → `run.bat`.
Build a standalone executable with `build.bat` (output: `dist\VideoGrabber.exe`).
Paste a link → Analyze → pick quality (up to 4K, or MP3) → download with a live queue.
Playlists, parallel downloads, cancel/retry and browser-cookie support are built in.
